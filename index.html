Model notes — what is real, what is a stand-in 
CONCEPT DEMO. All numbers on this page are computed live in your browser by a small
surrogate chain written for this demo (see app.js). The chain mimics the structure of the
proposed MD → DEM → FEM → cell → pack workflow; it is NOT validated simulation output.

Electrode:  porosity ε = 0.62 − 0.0016·P − 0.012·B + 0.03·(D−1) − 0.004·(D50−9)
            binder migration M grows with drying rate, falls with adhesion
            tortuosity τ = ε^(−0.55) · (1 + 0.35·M)   (Bruggeman-style)
Cell:       transport quality T = ε/τ; utilization U = T/(T+0.06)
            capacity Q = 3.40 · U^0.30 · (0.86 + 0.14·S) Ah, S = conductivity factor
Pack:       96 cells, per-cell porosity jitter σ from drying/calendering uniformity;
            usable pack = 96 × 5th-percentile cell capacity (series-string limit)
Life:       per-cell fade to 80% (RUL) from U, adhesion, migration and charge rate;
            reliability R(t) = exp(−(t/η)^2.4), η set by the batch median RUL
Memory:     variance shares from a 240-point Latin-hypercube sweep of the six knobs,
            squared Pearson correlation, normalized — genuinely recomputed per visit,
            not stored numbers.

In the full system each stand-in is replaced by the real model: LAMMPS (MD laws),
Yade/LIGGGHTS (DEM), FEniCSx + TauFactor (FEM/transport), PyBaMM (cell), and
physics-informed neural operators trained on that chain, exported to ONNX.

Built as a starting concept for discussion. Simulated data only; BEACONS pilot-line measurements slot into the same views as validation when available.
